
# Airlines Data Visualization and Analysis

This project focuses on the analysis and visualization of airline flight operations to identify patterns in flight delays and cancellations. Using large-scale aviation data, the project examines how operational, temporal, and seasonal factors impact airline performance.

Multiple data visualizations and dashboards were created to present insights on delay causes, airline and airport performance, route trends, and seasonal patterns. These visual outputs enable clear interpretation of complex data and support data-driven analysis.

https://github.com/user-attachments/assets/35ee9d63-b978-451d-a10a-2b9490b7f1c0

## Dataset

- Source: Kaggle
- Dataset: Flight Delay and Causes
- Link: https://www.kaggle.com/datasets/undersc0re/flight-delay-and-causes

The dataset is provided in this repository in compressed .csv.gz format to reduce storage size. It contains large-scale flight records, including airline details, airport information, delay durations, cancellation status, and delay causes.
## Tech Stack

- Python  
- pandas, numpy  
- matplotlib, seaborn, plotly  
- Power BI  
- Jupyter Notebook  

## Project Scope

* Analysis of flight delays and cancellations
* Airline and airport-level performance comparison
* Identification of major delay causes
* Seasonal and time-based trend analysis
* Visualization-driven insight generation

## Documentation

A detailed project report is included in the `reports` folder of the repository, covering the methodology, analysis process, and findings.

The interactive Power BI dashboard is available in the `visualization` folder for dynamic exploration of airline and airport performance.
